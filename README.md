# 花花记账 / Flower — Press images

[App Store](https://apps.apple.com/app/id6801466802)

花花记账是一个 iPhone 生活账本。可以装点的卡夹和城市烫印、在本地根据个人记录学习的消费习惯，以及地图、月度回顾和年鉴，是它的主要特点。

配图使用真实 App 界面局部及 App 导出的分享卡，来自已发布功能的历史演示素材；并非当前版本全新截图。图中的金额、地点与生活记录均来自演示账本。界面经过裁取和排版，没有生成或重画产品界面。外观和功能可用条件以 App 内说明为准。

- `01-cardholders-embossings.png`：旅行卡夹上的城市烫印，透明、花开与素色卡夹。
- `02-map-yearbook.png`：记账地图分享卡与花花年鉴。地图连接保存在账目的地点，不是连续 GPS 轨迹；本图为静态展示。
- `03-moments-habits.png`：月度回顾中的照片与长期习惯变化。

供花花记账相关编辑报道与产品介绍配图使用。产品美术与界面权利归其权利人，地图标识予以保留。
